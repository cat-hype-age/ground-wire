# Table Search Patterns

- Data for period X appears in bulletins published AFTER that period
- October/September bulletins are richest (fiscal year summaries)
- Search TABLE NAMES ("Table FD-1") not values
- Unit headers appear ABOVE tables, not in the table itself
- "Public debt" ≠ "total gross federal debt including agency securities"
- If a question says "total" and you found a single line item, look for a parent row
- Read the EXACT instrument name: "saving notes" ≠ "savings bonds", "Series E" ≠ "Series EE"
