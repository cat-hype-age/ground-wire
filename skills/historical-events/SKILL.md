# Historical Event → Year Reference

Questions may reference economic events instead of specific years. Use this lookup:

## Financial Crises
- **Great Depression**: 1929-1939 (stock crash: Oct 1929)
- **Dot-com bubble burst**: 2000-2002 (Amazon lowest stock: 2001)
- **Housing bubble / subprime crisis**: 2007-2008
- **Bank bailout (TARP)**: 2008 (signed Oct 2008)
- **Great Recession**: 2007-2009

## Policy Changes
- **Bretton Woods**: 1944 (agreement), ended 1971 (Nixon shock)
- **Gold standard ended**: 1971
- **Fiscal year change**: 1976 (June 30 → September 30)
- **Transition quarter**: July-Sept 1976

## Wars
- **WW2 start**: 1939 (Europe), 1941 (US entry)
- **WW2 end**: 1945
- **Korean War**: 1950-1953
- **Vietnam War**: 1955-1975 (major US: 1965-1973)
- **Gulf War**: 1990-1991

## When You See Event References
1. Map the event to a specific year using this table
2. If ambiguous (e.g., "during the housing crisis"), try the most commonly cited year
3. Write down the mapped year BEFORE searching the corpus
