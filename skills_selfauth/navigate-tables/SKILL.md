# SKILL: Treasury Bulletin Table Navigation

## What Worked
- Knowing to look in Capital Movements section for foreign holder data
- Finding the specific table with "Liabilities to Foreigners"
- Correctly identifying exact month/year values for CAGR calculations

## Standard Treasury Bulletin Sections
- **Capital Movements**: Banks, brokers, securities (most foreign holder data)
- **Federal Fiscal Operations**: Budget receipts, outlays, debt
- **U.S. Savings Bonds**: Sales, redemptions, outstanding
- **Federal Debt**: Public debt, agency obligations

## Finding the Right Table
1. Search for key terms from the question: "liabilities to foreigners," "budget receipts," "sales and redemptions"
2. Check table titles for exact terminology
3. Note the table code (e.g., CM.4, FFO.2) for future reference
4. Read column headers — they specify the data type

## CAGR Formula Reminder
For growth over multiple years:
```
CAGR = (Ending Value / Beginning Value)^(1/years) - 1
```
Years = difference in dates, not number of data points.
